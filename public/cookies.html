Cookies & local data

Updated 7 November 2026

No app tracking cookies

Drop does not set pairing cookies, install analytics or advertising SDKs, or read cookies from other websites. There are no optional trackers to enable, so there is no consent banner that does nothing.

A temporary room

Files and messages stay in page memory and are lost on reload. Drop uses sessionStorage in this tab for the room identifier, return credential, expiry and the owner’s invitation. Ending the room clears that entry. The server enforces expiry even if a browser restores an older tab.

The server retains an approved place for up to ten minutes away. This is a return window, not a promise that a phone will keep running transfers in the background. Downloads you explicitly save stay on your device.

Static offline assets

A service worker caches only the static offline error page, its interaction script and favicon after a successful online visit. No room pages, invitations, files or chat are cached. Clear the browser’s site data to remove this cache. A first-ever offline visit cannot install it.

Hosting and your controls

Hosting and network providers process metadata independently; see the privacy policy. Copying text or sharing an invitation requires your action. Drop does not monitor your clipboard.
